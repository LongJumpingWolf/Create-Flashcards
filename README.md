# Anki Flashcard Maker

A responsive Anki deck builder with PDF study and snipping tools. The project is organized as a frontend and API backend in one repository.

## Repository layout

- `frontend/` — React + Vite app
- `backend/` — FastAPI service that generates `.apkg` files

## Run locally

Start the backend in one terminal:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

Start the frontend in a second terminal:

```powershell
cd frontend
npm install
npm run dev
```

The Vite app uses `http://127.0.0.1:8000` for the backend in development. Set `VITE_BACKEND_URL` when deploying the frontend to point it at the deployed API.

## BeeRus card types and settings

Every deck exported from the site uses six note types: Basic - BeeRus, Cloze - BeeRus, Cloze (Sequential) - BeeRus, Image Occlusion - BeeRus, Image Occlusion (Sequential) - BeeRus and Image Occlusion (Random) - BeeRus. Each has four pill fields (Pill 1..4) that show as toggle buttons under the answer, so no Anki add-on is needed. The Settings page (header button, or `#settings`) edits pill labels/icons/colours, the optional watermark, fonts, colours, review keys and export limits, shows a live preview built from the same HTML/CSS as the export, and can download a test deck.

Pasting a ChatGPT answer into a pill keeps its look: selected text (HTML) is converted to clean semantic HTML wrapped in `<div class="gpt">`, and the Markdown from ChatGPT's Copy button is converted too when the pill's content format is "ChatGPT look". The note type's CSS (`gptCss` in `beerus.js`, sizes measured from a saved ChatGPT page) draws it, including Anki's night mode. A pill whose field is empty never appears on the card.

Pictures in a pasted ChatGPT answer: ChatGPT's clipboard carries a link to each picture (its CDN sends no CORS headers), so `api/proxy-image.js` (a Vercel function, mirrored in `npm run dev`) downloads allow-listed image hosts (see `src/imageHosts.js`) when a deck is exported and the images are stored in the deck; the editor shows them from the web in the meantime. The ChatGPT panel's spacing was measured against a saved ChatGPT page (16px/26px text, 16px between paragraphs, 8px before lists and after titles, 24px before titles, 14px tables).

The pill icon maker (`#icons`, linked from Settings) is a small canvas editor for icons: emoji, letters, built-in glyphs or a picture, background/outline, doodling, then export at 24-128 px as PNG or WebP with the live file size shown. A pill icon is stored once per deck (about 1-3 KB at 48 px) however many cards use it, and "Use as icon for" saves it straight into Settings.

The note types are built in `frontend/src/beerus.js`. The browser exporter uses them directly; the Python backend receives them in the request (`theme`) or falls back to `backend/beerus_default_theme.json`, generated by `node frontend/scripts/gen-python-templates.mjs` (run it after changing `beerus.js` or `sequentialTemplates.js`). Field lists are append-only so existing collections stay compatible.

## Vercel deployment

This repository uses two Vercel projects: `create-flashcards` builds from `frontend/`, and `create-flashcards-api` builds from `backend/`. The frontend's `VITE_BACKEND_URL` environment variable points to the API project. Vercel Function requests and responses are limited to 4.5 MB, so unusually large image-heavy decks may exceed the API's current hosting limit.
